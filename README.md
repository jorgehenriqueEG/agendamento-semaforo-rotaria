# Agendamento Semaforo Rotaria
## Descrição do Problema
Simula o ciclo de um semáforo em uma encruzilhada rotativa, calculando o tempo de espera médio para cada direção.
## Requisitos
* Definir duradas para verde, amarelo e vermelho.
* Calcular o ciclo total.
* Determinar a direção que fica mais tempo parada.
## Exemplo de Uso
Entrada: Duradas fixas por direção (Norte, Sul, Leste, Oeste).
Saída: Tempo de ciclo e direção com maior tempo de espera.
